# Трассировка правил агента

> **Статус:** производный неканонический пакет. Он не определяет и не расширяет Pokeball Core. Проверьте [BASELINE.md](BASELINE.md); приоритет имеет Core.

Единственные определения правил — в [AGENT-CONTRACT.md](AGENT-CONTRACT.md). Эта матрица направляет каждое правило к упорядоченному набору документов Core, применимости, его авторитетному источнику и проверке. `A/P/R/C` — четыре класса Core §0.2 и ограниченного индекса §20.1. Трассировка сравнивает каждое правило пакета с полной исходной записью Core и её полной проекцией §20; §20.1 проверяется только по объявленным столбцам применимости, владельца, источника и маршрута тестов. - Общая политика/механизм/доказательства могут один раз закрыть многие охваченные Ball в своих точных дайджесте и области.
- Политика может выбирать только варианты, которые Core оставляет открытыми. Ни политика, ни точный `WaiverRecord` не подавляют триггер, не ослабляют закон, не разрешают цикл прямого управления и не делают нарушение `MUST`/`MUST NOT` соответствующим.

## Проекция рабочего процесса человека

Core §21.7 и §§0.5/13.5/14.1–14.2 направляют повседневную работу над функцией к существующему коду и затронутым тестам, работу над привязкой к среде исполнения — к повторно используемым механизмам/доказательствам, заявления — к точной области промышленной эксплуатации. Core §5/PBA-01 позволяет самому проверяемому коду/привязке нести карту ролей/рёбер. У проверок установки потребителя и каталога переносимости сопровождающего пакет разные владельцы по `AP-GATE-10`. Ни один не добавляет ID правила, компонент, обязательный сценарий отсутствующего пути или сокращённый путь к заявлению.
