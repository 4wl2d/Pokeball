# Матрица обычных тестов

> **Статус:** производный неканонический пакет. Он не определяет и не расширяет Pokeball Core. Проверьте [BASELINE.md](BASELINE.md); приоритет имеет Core.

Используйте это продолжение для обычных изменений: выберите базовые тесты, активируйте только строки достижимых триггеров и не создавайте доказательства, нужные лишь для заявлений о гарантиях.

Все правила `PKB-AR-*` определены только в [AGENT-CONTRACT.md](AGENT-CONTRACT.md). Этот документ — руководство по задаче, производное от указанных исходных положений Core.

## 1. Обычное изменение

Обычная реализация не создаёт полное досье проверок. До правок разрешите:

```text
точная базовая версия и затронутый владелец полномочий
авторитетный источник и точная ссылка на политику, если используется
семантическое изменение
новые, удалённые и неизменившиеся триггеры
явные исключения из области работы
```

После правок запустите тесты поведения затронутого Ball и тесты, выбранные по изменённым триггерам. Повторно используйте существующие применимые доказательства привязки к среде исполнения в точной области; повторите или расширьте их, если изменение нарушает допущения об источнике, профиле, лимите, окружении или иных условиях. Базовые тесты не означают создание заново неизменного набора проверок привязки для каждого Ball. Сообщите diff, отличие политики, команды/результаты и нерешённые активированные решения. Не записывайте отсутствующие пути по отдельности, не создавайте заглушки `TriggerAbsenceProof` и не заявляйте о соответствии или более сильной гарантии. Доказательство материализуют, только когда заявление о соответствии/выпуске или принятое решение по неоднозначности опирается на отсутствие.
