# Feature source routes

Choose the row matching the source delta. Read complete linked sections, not every row. This is routing, not a second definition of Core.

| Task | Sources and useful checks |
|---|---|
| Business-rule change in an established feature | [§21.7 responsibility](../../spec/core/reference/21-adoption.md#217-everyday-development-and-production-responsibility), owning decision and its tests. If decision inputs change: [§8.1 context](../../spec/core/08-decision-and-acceptance.md#81-decisioncontext), [§8.2 determinism](../../spec/core/08-decision-and-acceptance.md#82-determinism). |
| First feature or new mutation form | [§3.3 operation forms](../../spec/core/03-model-boundaries-zones.md#33-canonical-mutation-and-read-forms), [§14.1 source contract](../../spec/core/14-manifest-and-organization.md#141-role-of-the-manifest), [§14.2 present fields](../../spec/core/14-manifest-and-organization.md#142-minimal-core-manifest). Resolve the writer/acceptance through the binding workflow if none exists. |
| State ownership or data surviving to a later decision | [§7.1 state kinds](../../spec/core/07-state-and-authority.md#71-state-kinds), [§7.2 authority](../../spec/core/07-state-and-authority.md#72-one-mutable-factone-authority), [§7.5 captured input](../../spec/core/07-state-and-authority.md#75-captured-input), [§7.6 writer](../../spec/core/07-state-and-authority.md#76-single-writer). Preserve the later consumer's required lineage. |
| Input representation versus a business constraint | [§5.1 Interaction](../../spec/core/03-model-boundaries-zones.md#51-interaction-hemisphere), [§5.2 Nucleus](../../spec/core/03-model-boundaries-zones.md#52-protocol-nucleus), [§6.13 error stages](../../spec/core/06-protocol-algebra.md#613-error-classes). State/context-dependent rejection belongs to the decision. |
| New or changed protocol variant | [§6.14 closure](../../spec/core/06-protocol-algebra.md#614-protocol-closure), then the relevant category in [protocol routes](protocol.md); select that category, not the whole table. |
| Local query or view policy | [§6.3 Query](../../spec/core/06-protocol-algebra.md#63-query), [§8.10 read](../../spec/core/08-decision-and-acceptance.md#810-local-read). Read results do not initiate a target decision/commit or effects. |
| Present variable input, State, outputs or decision work | [§8.3 bounded decision](../../spec/core/08-decision-and-acceptance.md#83-bounded-decision), [§13.1 limit classes](../../spec/core/12-profiles-and-limits.md#131-three-classes-of-limits). Reuse construction proofs or the exact scoped bound. |
| Actor-dependent decision/read, new I/O or trust boundary | [§11.1 quarantine](../../spec/core/11-security-and-privacy.md#111-double-quarantine), [§11.2 actor](../../spec/core/11-security-and-privacy.md#112-actor-context), [§11.3 gates](../../spec/core/11-security-and-privacy.md#113-policy-gate-and-execution-gate); continue to the changed capability, grant or sink heading only when present. |
| Verify the changed transition | Relevant [§17.1 transition](../../spec/core/verification/17-01-transition-and-property-tests.md#171-transition-tests) or [§17.2 property](../../spec/core/verification/17-01-transition-and-property-tests.md#172-property-based-tests) cases. Reuse still-applicable binding evidence. |
