### 6.4. Effect

> Derived excerpt of Pokeball Core §6.4. This packaged reference adds no architectural authority or rules; the original Core remains normative. Source section: 6.4. Effect.

**Effect** — a private declarative external operation of the owning Ball.

```text
FindProducts(query, pageSize)
PersistSession(snapshot)
ReadCurrentTime
CaptureProviderPayment(...)
```

An `Effect` describes a permitted action, not a service object or function call.
