### 17.10. Observability

> Derived excerpt of Pokeball Core §17.10. This packaged reference adds no architectural authority or rules; the original Core remains normative. Source section: 17.10. Observability.

Recommended causal fields for paths that materialize them:

```text
ballType
ballInstanceId
commitRevision
pulseType
semanticHandle
operationId
outputId when available
stateRevisionBefore/After
attemptId
outcome
latency
traceId
```

An operational trace, security audit, and exact replay data are distinct artifacts. A redacted trace does not guarantee replay.
