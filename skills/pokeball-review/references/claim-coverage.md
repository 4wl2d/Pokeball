# Explicit claim coverage

Use this reference only for an explicitly requested conformance or guarantee assessment. Start with the exact claim and the applicable path/risk/profile inventory. The complete source sections below are bundled so that relevant obligations can be resolved without another artifact download. Select the affected sections; a present claim does not make every unrelated profile applicable. Read the full claimed scope before giving a verdict.

This navigation index is derived guidance, not an additional ruleset. §5 includes the always-applicable logical-role source record before its detailed role subsections. Review the applicable verification and checklist sections along with the source requirements.
